プライバシーポリシー

最終更新日: 2026年5月10日

はいとうポケット（以下「本アプリ」）は、dice_apps（以下「当方」）が提供するiOS向けの株式ポートフォリオ管理アプリです。本プライバシーポリシーは、本アプリにおける情報の取り扱いについて説明します。

1. 収集する情報

1-1. ユーザーが入力するデータ

本アプリでは、ユーザーが以下のデータを入力・管理します。これらのデータは端末内（SwiftData）に保存され、当方のサーバーには送信されません。

  • ポートフォリオ情報（保有銘柄、株数、取得単価等）
  • 分析メモ（銘柄に対する評価・メモ）
  • 口座情報（口座名称）
  • アプリ設定（表示設定、カスタム指標等）

1-2. 自動的に収集される情報

本アプリでは、以下の目的で第三者サービスを利用しており、これらのサービスが自動的に情報を収集する場合があります。

広告配信（Google AdMob）

本アプリでは、広告表示のためにGoogle AdMobを使用しています。AdMobは、広告のパーソナライズや効果測定のために以下の情報を収集する場合があります。

  • デバイス識別子（広告ID / IDFA）
  • デバイス情報（機種、OS バージョン等）
  • IPアドレス（おおよその位置情報の推定に使用）

詳細は Google のプライバシーポリシー をご確認ください。

データ取得（Firebase / Cloud Firestore）

本アプリでは、銘柄マスタデータ、ランキング情報、財務データ等のサーバーデータの取得にFirebase / Cloud Firestoreを使用しています。ユーザーの個人情報をFirestoreに保存・送信することはありません。

2. iCloudバックアップ

本アプリは、ユーザーの任意操作により、iCloud Driveへのデータバックアップ機能を提供します。バックアップされるデータは以下の通りです。

  • ポートフォリオ情報
  • 資産スナップショット
  • 分析データ
  • 口座情報
  • アプリ設定（セクターアイコン、カスタム指標、表示設定等）

iCloudへのデータ保存はApple社のプライバシーポリシーに準じます。詳細は Apple のプライバシーポリシー をご確認ください。

3. サブスクリプション

本アプリでは、プレミアム機能の提供のためにApp内課金（自動更新サブスクリプション）を利用しています。課金処理はすべてApple社のApp Store経由で行われ、当方がクレジットカード情報等の決済情報を取得・保存することはありません。

4. データの第三者提供

当方は、法令に基づく場合を除き、ユーザーの個人データを第三者に提供することはありません。ただし、前述の広告サービス（Google AdMob）により、広告目的で情報が収集される場合があります。

5. データの保護

ユーザーデータは端末内のSwiftDataデータベースに保存され、外部サーバーへの送信は行いません。iCloudバックアップを利用する場合は、Apple社のセキュリティ対策により保護されます。

6. お子様のプライバシー

本アプリは、13歳未満のお子様を対象としておりません。13歳未満のお子様から意図的に個人情報を収集することはありません。

7. プライバシーポリシーの変更

本プライバシーポリシーは、必要に応じて更新することがあります。変更があった場合は、本ページにて通知します。
